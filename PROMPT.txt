BUILD SPEC
--------------------------------------------------------------------------------
Stack:
  - Next.js (App Router) + TypeScript + Tailwind
  - Firebase Auth + Firestore
  - Deploys to Cloudflare Pages (free, no card)

Pages:
  1. Home - hero (name, one-line positioning, contact links), projects grid,
     contact form
  2. /projects/[slug] - per-project page: the problem, the stack, ONE decision
     I made and why, live link, repo link

Data:
  - Projects stored in a Firestore collection called "projects"
  - Contact form writes to a Firestore collection called "messages"
  - Small typed data layer, keep it clean

Scope control - IMPORTANT:
  - Keep it SMALL. Three projects, done properly, beats twelve thin ones.
  - No contact form spam protection, analytics, dark-mode toggle, cookie
    banner, test suite, or CI unless trivial. Ship it live, then improve.
  - I want a deployed URL more than I want perfect code.

The three projects to seed into Firestore:
  1. "Stock Footage Matcher" - Python. A five-stage pipeline (analyze, caption,
     match, download, output) that aligns stock footage to a voiceover script
     using embedding search + LLM matching, with checkpointed state that
     resumes after failure, and exports OTIO/EDL/XML timelines.
  2. "Community Reference Site" - WordPress + Elementor. (URL pending - leave a
     placeholder I can fill in later.)
  3. "Voice Transcription Tool" - Python. Abstracted STT provider layer across
     three backends, NumPy-vectorized VAD, non-blocking transcription.
